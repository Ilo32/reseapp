## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

You can start editing the page by modifying `app/page.tsx`. The page auto-updates as you edit the file.

This project uses [`next/font`](https://nextjs.org/docs/app/building-your-application/optimizing/fonts) to automatically optimize and load [Geist](https://vercel.com/font), a new font family for Vercel.

## Reflection

Types were quite annoying for me to deal with but it was simple enough so I decided to just let Claude handle it.

What went quite fast is to use Claudes draft for a layout and then making it into a reality using HTML and Tailwindcss code.

I believe that using Claude or any other AI tool could be quite beneficial, if used correctly, in moderation and whilst moderating it's output; ensuring it doesn't replace you but rather assists you.
